Página de teste do navegador de prova

Spec 005 do fps-exam-browser. Cada bloco diz o que deve acontecer.

Bloco 01 — link para site fora do perfil

Abrir https://www.google.com/

Esperado: barrado; aparece "Site não permitido nesta prova" (CA-001).

Bloco 02 — redirecionamento para fora do perfil

httpbin.org redireciona para google.com

Esperado: o httpbin abre, o redirecionamento é barrado e a página local mostra google.com (CA-008).

Bloco 03 — link para página permitida

Abrir permitido.html

Esperado: abre na mesma janela.

Bloco 04 — links que pedem nova janela

target=_blank para permitido.html · target=_blank rel=noopener para permitido.html · target=_blank para google.com · target=_blank rel=noopener para google.com

Esperado: nenhuma janela nova, nem atrás. Permitido abre na mesma janela; fora do perfil é barrado (CA-005, RF-009).

Bloco 05 — window.open pela página

Esperado: nenhuma janela nova (CA-005).

Bloco 06 — download de PDF

Baixar prova.pdf · Abrir prova.pdf (sem o atributo download)

Esperado: nada é baixado e nenhuma caixa de diálogo abre (CA-006). Com o perfil que libera downloads, baixa (CA-009).

Bloco 07 — anexo enviado pelo servidor

httpbin.org devolve como anexo

Esperado: nada é baixado (CA-006). O GitHub Pages não deixa escolher cabeçalho, por isso o httpbin.

Bloco 08 — download gerado por script (blob:)

Esperado: nada é baixado.

Bloco 09 — quadro embutido de site fora do perfil

Esperado: o quadro é barrado e a decisão aparece no registro; o resto da página carrega (CA-014).

Bloco 10 — quadros sem endereço (about:blank e srcdoc)

Esperado: os dois carregam (folga só para about:blank e about:srcdoc dentro de quadro).

Bloco 11 — quadro dentro de quadro

Esperado: o de fora carrega; o de dentro (example.com) é barrado.

Bloco 12 — recursos da própria página e de outro domínio

Script da página: script NÃO carregou

Esperado: a imagem verde, o ícone do Google e "script carregou" aparecem: recursos passam, só a navegação é filtrada (CA-014, RF-010).

Bloco 13 — PDF externo embutido

Esperado: barrado (domínio fora do perfil), ou registrado no relato se o motor tratar como recurso.

Bloco 14 — imprimir pela página

Esperado: nenhuma caixa de impressão.

Bloco 15 — escolher arquivo

Só registrar o que acontece (issue 61 — diálogos do sistema abertos pela página).

Bloco 16 — esquemas que não são https

data:text/html · view-source: · edge://settings · about:blank

Esperado: todos barrados na página principal.

Bloco 17 — about:blank com conteúdo escrito por script

Esperado: barrado; o texto "conteúdo escrito em about:blank" não aparece.
